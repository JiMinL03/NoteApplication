# Simple CRUD Notepad

## 프로젝트 설명

이 프로젝트는 간단한 CRUD(Create, Read, Update, Delete) 작업을 통해 메모를 관리할 수 있는 메모장 애플리케이션입니다

## 주요 기능

- **메모 추가**: 새 메모를 작성하고 저장할 수 있습니다
- **메모 읽기**: 저장된 메모를 확인할 수 있습니다
- **메모 수정**: 기존 메모를 수정할 수 있습니다
- **메모 삭제**: 메모를 삭제할 수 있습니다

## 기술 스택

- **프로그래밍 언어**: Kotlin, Java
- **프레임워크**: Android SDK 35
- **저장소**: SQLite
- **UI 구성**: Fragment, RecyclerView, Activity

## 개발 순서

### 1. **프래그먼트 개발**

- **목표**: 화면 전환이 필요할 때 프래그먼트 사용
- **프래그먼트**:
  - `NoteDetailFragment`: 메모를 클릭할 시, 상세 메모를 볼 수 있는 화면으로 전환
  - `NoteFormFragment`: 메모를 새로 추가할 수 있는 화면

### 2. **리사이클러뷰 설정**

- **목표**: 메모 목록을 표시할 때 효율적으로 데이터를 관리하고 표시하기 위해 `RecyclerView`를 사용
- **리사이클러 뷰**:
  - `RecyclerView.Adapter`와 `RecyclerView.ViewHolder`를 구현하여 각 메모 항목을 표시
  - `RecyclerView`는 `NoteListFragment`에서 사용되며, 메모 목록을 효율적으로 표시
  - `NoteAdapter`: 메모 항목을 리스트 형태로 보여주는 어댑터

### 3. **데이터베이스 연동**

- **목표**: 메모를 앱에 저장하고, 수정하고, 삭제할 수 있도록 데이터베이스와 연동
- **구현 단계**:
  - **SQLite** 를 사용하여 메모를 로컬 데이터베이스에 저장

### 4. **메모 추가, 수정, 삭제 기능 구현**

- **목표**: SQLiteOpenHelper를 상속받아 메모를 관리하는 데이터베이스 헬퍼 클래스를 구현
- **구현 단계**:
  - **메모 추가**: addNote 메서드를 사용하여 메모를 데이터베이스에 추가
  - **메모 수정**: updateNote 메서드를 사용하여 특정 메모의 제목과 내용을 수정
  - **메모 삭제**: deleteNote 메서드를 사용하여 메모를 삭제
  - **메모 조회**: getAllNotes 메서드를 사용하여 모든 메모를 조회. searchByTitle 메서드를 사용하여 제목을 기준으로 메모를 검색
